
# textadventure.py

This skript let's the user play a simple textadventure. Upon seeing a printed scene description, the user will be prompted to give keyborad input to complete the given story task of getting a book from the library. Two scenes require the user to solve a riddle, generated using the 'nltk' pakage.

***

## Requirements
`nltk` [(Download and Instructions)](https://www.nltk.org/install.html)

(All required resources will be downloaded to the default location)

***

## Usage
python3 textadventure.py
